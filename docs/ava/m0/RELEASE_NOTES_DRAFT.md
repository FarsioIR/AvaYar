# Ava M0 — Release Notes Draft

Release status: **DRAFT — DO NOT PUBLISH BEFORE MERGE**

## Purpose

Establish Ava as a Farsio product with a clear problem statement, MVP contract, and auditable GitHub delivery lifecycle.

## Included

- Ava product definition.
- MVP scope and acceptance criteria.
- Full vs Summary Persian listening modes.
- Translation-to-Persian requirement for non-Persian sources.
- Male/Female Persian voice requirement.
- GitHub lifecycle policy.
- Sanitized M0 baseline evidence.

## Release gate

The final GitHub Release must be created only after:

1. the M0 PR is merged,
2. required checks/evidence are accepted,
3. the exact merged commit SHA is resolved,
4. the release tag is created on that exact SHA.

## Known limitation

This M0 release establishes the product/delivery baseline. It does not by itself certify that the complete runtime MVP is already implemented.
